The whole journey, in words.

ONE FUNCTION. TWO ESSENTIAL INGREDIENTS.
1

Make the problem smaller.

For a positive integer n, n! = n × (n − 1)!. The calls go from 4 to 3 to 2 to 1 to 0. Each call waits for the next one to return before finishing its multiplication.

2

Reach an answer you already know.

The base case is 0! = 1. It returns immediately. Because the input decreases by one each time, every valid nonnegative integer input eventually reaches this stopping point.

3

Return, combine, repeat.

The answers travel back: factorial(0) returns 1; factorial(1) returns 1 × 1 = 1; factorial(2) returns 2 × 1 = 2; factorial(3) returns 3 × 2 = 6; factorial(4) returns 4 × 6 = 24.

The function behind the animationJavaScript
function factorial(n) {
  if (n === 0) return 1;
  return n * factorial(n - 1);
}

factorial(4); // 24
Input: a nonnegative integer.
A base case + progress toward it = a finite chain of calls.

In mathematics, this is a recursive definition. In code, the call stack keeps track of the unfinished work. The same dependency pattern connects both.
